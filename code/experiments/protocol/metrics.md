# 评估指标协议

本文件定义发布包中使用的误差指标与报告口径。训练损失见 `loss.md`；
时间处理见 `time.md`。

## 1. 短窗口评估

主表采用固定单窗口预测：

| 项 | 值 |
|---|---|
| 输入 | 帧 0–9（`steps = [time_window]`，不随机） |
| 输出 / 标签 | 帧 10–19 |
| 前向次数 | 1 次，无自回归滚动 |
| 参与评估的帧 | 0–19 |

plume-1D 与 plume-2D 的短窗口结果都使用这一口径，跨子集比较是公平的。
多窗口接续的长程评估见 `E03_rollout/`，它使用全时程数据，不在本节的
10→10 口径内。

## 2. 各模型生成 10 帧输出的方式

输出帧数已对齐为 10，但生成方式由模型架构决定：

| 模型 | 输出方式 | 前向次数 | 第 q 个输出帧的依据 |
|---|---|---|---|
| MPNN / MFGNO | 一次输出 `[N, time_window, 6]` | 1 | 真值输入帧 0–9 |
| GNOT | 一次输出 `time_window × 6` 后 reshape | 1 | 真值输入帧 0–9 |
| FNO | 逐帧自回归 | 10 | 自己预测的前 9 帧 |
| Transolver | 逐帧自回归 | 10 | 自己预测的前 9 帧 |

FNO 与 Transolver 的每次前向只产生一帧，因此第 $q$ 帧会累积 $q-1$ 次
自预测误差；MPNN / MFGNO / GNOT 的每一帧都直接建立在真值输入之上。
阅读主表时应把这一差异视为架构属性，而不是评测差异；比较 MFGNO 与
FNO / Transolver 时，不能把全部优势归因于算子设计。

FNO / Transolver 的训练与推理都按同样的逐帧方式展开，口径自洽。
E02 的 A/B/C 消融不受影响：三者同为一次输出，前向次数相同。

## 3. 逐帧逐场相对 L2 误差

对归一化空间面积权重 $a_i$（$\sum_i a_i = 1$）、轨迹 $n$、输出帧 $q$、
通道 $c$：

```text
e[n,q,c] = sqrt( Σ_i a_i · (pred[n,q,i,c] − truth[n,q,i,c])² )
           ─────────────────────────────────────────────────────
           max( sqrt( Σ_i a_i · truth[n,q,i,c]² ), ε_c )

E[c] = mean_n( mean_q( e[n,q,c] ) )
```

聚合次序是固定的：先按帧平均，再按轨迹平均。不能改成"对整条轨迹取一个范数"，
两者数值不同。

### 面积权重

- 128×128 均匀网格：$a_i = 1/N$，权重在分子分母中约去。
- 原始 401×309 非均匀网格：使用对应物理面积。短窗口主结果全部在 128×128
  网格上计算；`eval_metrics.py` 的 `area_weights` 分支保留了非均匀支持，
  但发布包的生产路径不启用它。

### ε_c（范数稳定项）

$\varepsilon_c$ 必须在测试评估前声明，并报告触发次数：

| 通道 | 取值规则 |
|---|---|
| ro, pr, tk, nu | 该通道训练集 $\sqrt{\text{mean}(truth^2)}$ 的 $10^{-6}$ 倍 |
| vx, vy | 同上；速度接近零时分母主导，必须同时报告 RMSE |

具体数值由训练文件现算，不预先写入固定值。每次评估输出
`epsilon_triggered_count[c]`；该计数非零时，对应通道的相对 L2 需谨慎解读。

### 场表示

- 误差在归一化后的文件表示上计算，与训练输入同尺度。
- `nu` 通道的误差是 $\log_{10}(\eta)$（$\eta$ 单位 Pa·s）的误差，
  不是黏度本身的相对误差。
- `pr` 是总压力（含静岩分量）。I2VIS 的动量方程保留重力体力项与压力梯度项，
  因此导出的压力不是动压力；它包含大背景分量，不是脉动量。

## 4. 辅助指标

| 指标 | 定义 | 用途 |
|---|---|---|
| RMSE | $\sqrt{\text{mean}_\Omega((pred−truth)^2)}$ | 保留文件尺度，与 L2RE 互补 |
| skill | $1 − \text{SSE}_{model} / \text{SSE}_{baseline}$ | 相对持续性基线的技能；正值优于基线 |
| persistence L2RE | 基线自身的逐场 L2RE | 判断预测是否只复现了背景场 |

基线定义：

- 短窗口（10→10）：基线 = 最后一个输入帧 $t=9$，对全部输出帧恒定。
- 自治 rollout：基线 = 首帧 $t=0$，对全部后续帧恒定；不得每步读取真值上一帧。

skill 的分母为零时记为未定义，不得用极小常数生成任意大的数值。

## 5. 不确定性与比较

- **训练种子不确定性**：报告多种子均值 ± 标准差。plume-1D 主结果使用
  3 个预设种子；单种子配置在表中标注，不写 ± SD，也不据此声称显著性。
- **测试轨迹不确定性**：对独立测试轨迹做有放回 bootstrap（固定 seed 与重复次数），
  报告逐轨迹指标均值的 95% percentile CI；所有模型使用同一组重采样索引。
- **配对比较**（如 $E_B − E_C$）：先逐轨迹相减，再重采样；同一轨迹的帧
  不视为独立样本。
- CI 只量化测试轨迹的采样差异，不包含训练随机性与调参选择偏差。

## 6. 报告纪律

- 六场逐场报告，不合并成单一平均分。
- 主表给种子均值 ± SD；配对差异另给轨迹级 bootstrap 区间，两者分列。
- 速度改善与标量退化并列报告，不追求"六场全胜"。
- 标量差异不显著不等于等价；若声称影响很小，须预先设定实际差异阈值并给出区间。
